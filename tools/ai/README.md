This directory contains information useful to AI, and tools
written/maintained with them.  The APSW module itself is all human
written, as are the main tests, and will remain that way.

Information includes good places and methods to hunt for bugs.

The tools are only ever run by maintainers and are used to cross check
code and data, and to generate checking code such as by inspecting
SQLite's mutex usage.  They extend testing far beyond what the
standard test suite does.
